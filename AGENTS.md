# Notes for AI coding agents

This is a small, self-contained starter project (a plain HTML/CSS/JavaScript page with no build step). Treat it as a developer's own project that they're about to add a rich text editor to.

## About this app
- It's intentionally minimal and partly placeholder — no rich text editor is integrated yet. Adding one is the task you'll be given.
- The **About** section is plain text marked as the editable region. Keep the no-build, plain-static approach.

## Ground rule: stay inside this directory
- Treat **this project directory as the entire codebase**. Do all your reading, searching, and work here.
- Do **not** read, open, or search files outside this directory — not parent directories, sibling folders, or anything else on this machine — for guidance, examples, or context. A developer integrating into their own project wouldn't have access to any of that, and neither should you.
- Using your normal tools, any documentation the task points you to, and the public internet is expected and fine — the rule above is only about not snooping unrelated local files.
